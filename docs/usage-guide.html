1 💻 电脑端使用方法

🖱️ 方法一：直接双击 HTML 文件打开

  1. 1

    找到下载好的 english-quiz-master 文件夹

  2. 2

    双击打开文件夹中的 index.html 文件

  3. 3

    系统会用默认浏览器打开，就可以开始使用啦！

💡
推荐浏览器：Chrome、Edge、Safari、Firefox 都可以，建议使用最新版本获得最佳体验。

🌐 方法二：GitHub Pages 在线使用

  1. 1

    打开浏览器，访问你的 GitHub Pages 地址：

    https://wan-wen-hao.github.io/english-quiz-master/

    把这个网址收藏到书签，随时打开就能用

  2. 2

    直接在线使用，数据保存在浏览器本地

💾 数据保存说明

✅
你的错题和进度数据都保存在浏览器的本地存储（localStorage）中。
• 只要不清除浏览器数据，就不会丢失
• 换浏览器、换电脑、换手机 = 数据不通用
• 建议定期备份重要数据

2 📱 手机端使用方法（重点！）

⚠️
重要提醒：手机上如果直接打开多文件版可能因为安全限制加载失败，强烈建议使用单文件版，完全离线可用！

📲 方法一：单文件版直接用（最推荐）

单文件版把所有内容都打包在一个 HTML 文件里，传到手机上就能用，完全离线！

📤 第一步：把文件传到手机上

  1. 1

    在电脑上下载好 单文件版 的 HTML 文件

  2. 2

    用以下任意一种方式传到手机：

    • 📧 发邮件给自己，手机上收邮件下载
    • 💬 微信/QQ 文件传输助手发送
    • ☁️ 上传到网盘（百度云/阿里云等），手机端下载
    • 🔌 用数据线连接电脑和手机传输

  3. 3

    把文件保存到手机上你能找到的位置

📖 第二步：用浏览器打开

  1. 1

    在手机的「文件」应用里找到刚才下载的 HTML 文件

  2. 2

    点击文件，选择用浏览器打开

    推荐使用：Chrome、Safari、Edge

  3. 3

    打开后就可以开始答题啦！🎉

🏠 第三步：添加到主屏幕（像 APP 一样用）

添加到主屏幕后，点击图标就能直接打开，跟 APP 一模一样！

🍎
iOS（iPhone / iPad）操作步骤：
  1. 1

    用 Safari 浏览器 打开 HTML 文件

  2. 2

    点击屏幕底部中间的 分享按钮（方框带向上箭头的图标 ⬆️）

  3. 3

    往下滑动，找到并点击 「添加到主屏幕」

  4. 4

    可以改个名字（比如「英语答题」），然后点击右上角的 「添加」

  5. 5

    回到手机桌面，你会看到一个新图标！点击就能直接打开使用 ✨

🤖
Android（安卓）操作步骤：
  1. 1

    用 Chrome 浏览器 打开 HTML 文件

  2. 2

    点击右上角的 三个点 ⋮ 菜单按钮

  3. 3

    找到并点击 「添加到主屏幕」 或 「安装应用」

  4. 4

    点击「添加」或「安装」确认

  5. 5

    回到手机桌面，找到新图标点击就能打开啦！🎉

✨
添加到主屏幕的好处：
• 全屏显示，没有浏览器地址栏，更像原生 APP
• 点击图标秒开，不用每次找文件
• 支持离线使用（单文件版）

3 🐙 GitHub 更新步骤（超详细）

当题库或功能有更新时，按照下面的步骤上传到 GitHub，GitHub Pages 就会自动更新。

📤 方法一：直接上传文件（最简单，适合新手）

  1. 1

    打开浏览器，访问你的 GitHub 仓库页面

    https://github.com/wan-wen-hao/english-quiz-master
  2. 2

    点击页面上的 Add file 按钮，选择 Upload files

    （Add file 在绿色的 Code 按钮右边）

  3. 3

    把新文件拖拽到上传区域，或者点击 choose your files 选择文件

    ⚠️
    注意文件路径要对！比如 index.html 要直接放在根目录，data 文件夹里的文件要上传到 data 文件夹中。如果路径不对，页面会加载失败。
  4. 4

    在页面下方的 Commit changes 区域：

    • 在第一个输入框填写提交说明，比如 更新题库 或 v8.0 更新
    • 确认选中 Commit directly to the main branch
    • 点击绿色的 Commit changes 按钮

  5. 5

    等待 2-5 分钟，GitHub Pages 就会自动更新

    （GitHub Pages 部署需要一点时间，不是即时的）

  6. 6

    确认更新成功：

    • 打开你的 GitHub Pages 页面
    • 按 Ctrl + F5（Windows）或 Cmd + Shift + R（Mac）强制刷新
    • 手机上：在浏览器设置里清除缓存，或用无痕模式打开验证

❓ 常见问题：为什么更新了还是旧版本？

🔄
这是浏览器缓存的问题！
浏览器为了加快加载速度，会把网页文件保存在本地。即使服务器更新了，浏览器可能还在用旧的缓存文件。

解决方法：

  1. 1

    电脑端：按 Ctrl + F5（Windows）或 Cmd + Shift + R（Mac）强制刷新

  2. 2

    手机端：在浏览器设置里清除缓存，或用无痕模式 / 隐身模式打开验证

  3. 3

    如果还是旧版本，可能是 GitHub Pages 还没部署完成，再多等几分钟再试

5 ❓ 常见问题 FAQ

Q: 手机上打开白屏/加载不出来怎么办？
用单文件版！多文件版（有 data 文件夹的版本）直接在手机上打开会因为浏览器安全限制导致 JSON 文件加载失败。单文件版把所有数据都打包在一个 HTML 里，完全离线可用，不会有这个问题。
Q: 错题和进度会丢吗？
数据保存在浏览器的本地存储（localStorage）里，只要不清除浏览器数据就不会丢。但是：
• 换浏览器 = 数据不通用
• 换手机/电脑 = 数据不通用
• 卸载浏览器或清除数据 = 数据会丢失

建议：重要的错题可以截图保存。
Q: 怎么把进度从电脑传到手机？
目前还不支持云同步功能，进度和错题数据只能在当前浏览器中使用。后续版本可能会加入导出/导入功能。
Q: 需要联网吗？
单文件版完全离线，不用网！下载后传到手机上，随时随地都能刷题。
GitHub Pages 在线版需要联网才能访问。
Q: iOS 上怎么添加到主屏幕？
Safari 打开 → 分享按钮（底部中间 ⬆️）→ 添加到主屏幕 → 添加
注意：必须用 Safari 浏览器，Chrome 等第三方浏览器在 iOS 上不支持「添加到主屏幕」的 PWA 功能。
Q: Android 上怎么添加到主屏幕？
Chrome 打开 → 右上角三个点 ⋮ → 添加到主屏幕 / 安装应用 → 添加
不同品牌的手机菜单名称可能略有不同，一般叫「添加到主屏幕」「安装应用」或「添加到桌面」。
Q: 单文件版和多文件版有什么区别？
单文件版：所有内容都在一个 HTML 文件里，文件较大但使用简单，适合手机端和本地使用，完全离线。
多文件版：数据分开放在 data 文件夹里，结构清晰方便修改，适合部署到 GitHub Pages 或本地服务器。

功能完全一样，只是打包方式不同。
Q: 怎么删除错题？
打开「错题本」页面，点击右上角的 「清空错题本」 按钮可以清除所有错题。目前暂不支持删除单条错题。

对比项 单文件版 多文件版

手机直接打开 ✓ 完美支持 ✗ 会加载失败
离线使用 ✓ 完全离线 ✓ 本地服务器可用
GitHub Pages 部署 ✓ 可以 ✓ 推荐
修改数据方便度 ✗ 较麻烦 ✓ 分开编辑很方便
