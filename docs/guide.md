# 英语全能刷题王 使用指南

本指南面向最终用户，介绍如何使用「英语全能刷题王」题库进行英语刷题与自测。题库文件位于 `data/quiz-bank.json`，包含 **4 个等级、共 120 道题目**，采用**语法优先（Grammar-First）**分类法。v3.0.0 新增每题**词汇解析（vocabulary）**、**全句翻译（sentenceTranslation）**及**阅读理解题型（passage）**。

---

## 一、题库总览

题库按四个等级组织，难度由低到高：

| 等级 | 中文名 | 题目 ID 前缀 | 题目数 | 适合人群 |
|------|--------|-------------|--------|----------|
| `junior` | 初中 | `j_` | 30 | 初中生、英语零基础入门者 |
| `senior` | 高中 | `s_` | 30 | 高中生、高考备考者 |
| `cet4`   | 四级 | `c4_` | 30 | 大学生、四级备考者 |
| `cet6`   | 六级 | `c6_` | 30 | 大学生、六级备考者、考研党 |

**每个等级 30 题，题型分布完全一致（v3.0.0 更新）：**

- 选择题（choice）：10 题
- 判断题（truefalse）：6 题
- 填空题（fillblank）：6 题
- 问答题/翻译题（qa）：5 题
- 阅读理解题（passage）：3 题（v3.0.0 新增，每题含短文及 2-3 道子题）

每个等级内部的题目由易到难排列，建议按顺序刷题。

## 二、分类体系详解：语法优先（Grammar-First）

本题库 **v2.0** 起不再使用"词汇/语法/翻译"的分类方式，而是以**语法结构、句型与特殊用法**为分类主线。词汇在语法语境中自然出现，不作为独立分类维度。

### 为什么改用语法优先？

1. **零基础学习者**最需要掌握的是**句法骨架**（be 动词、时态、从句、倒装等），而非孤立背单词。
2. **词汇在语境中习得更高效**：一道考查被动语态的题目会自然涉及各种动词，但测试的是被动结构本身。
3. **解析聚焦语法规则**：每题解析讲解语法规则，而非翻译单词含义，真正做到"授人以渔"。

### v3.0.0 新增增强

在语法优先分类的基础上，v3.0.0 新增了两项重大增强：

- **词汇解析（vocabulary）**：每道题都新增 `vocabulary` 字段，包含 2-5 个核心词汇，每个词汇含 `word`（单词）、`pos`（词性，如 n./v./adj./prep.）、`meaning`（中文释义）。学习者可以在理解语法规则的同时，精确定位并记忆关键词汇。
- **全句翻译（sentenceTranslation）**：每道题都新增 `sentenceTranslation` 字段，提供英文句子/题干的完整中文翻译。与 `questionCn`（题干释义）不同，`sentenceTranslation` 是将完整英文句子翻译成自然流畅的中文，便于对照学习。
- **阅读理解题型（passage）**：每个等级新增 3 道 passage 题。每题包含一段英文短文（`passage`）、中文翻译（`passageCn`）、词汇列表（`vocabulary`）和 2-3 道子题（`subQuestions`）。子题类型为 choice 或 truefalse，测试在语篇中的语法结构理解能力，而非单纯内容记忆。

## 三、快速开始

### 1. 选择等级
打开刷题页面后，先选择一个等级（初中 / 高中 / 四级 / 六级）。如果是零基础，建议从「初中」开始。

### 2. 逐题作答
题库提供四种题型，作答方式略有不同：

#### 选择题（choice）
- 题目会给出四个选项 `A / B / C / D`（类似驾考科一）。
- 点击你认为正确的选项即可。
- 系统会自动判分，答案为单个字母（如 `A`）。

#### 判断题（truefalse）
- 阅读英文句子，判断其语法/语义是否正确。
- 答案为 `true`（正确）或 `false`（错误）。
- 系统自动判分。

#### 填空题（fillblank）
- 题干中用 `___` 标出空缺处。
- 在输入框中填写答案（英文单词或短语）。
- 判分建议：忽略大小写与首尾空格后与参考答案比对。
- 若答案为动词等，请注意时态/形式要与题干一致。

#### 问答题/翻译题（qa）
- 主观题，请先自己作答，再查看参考答案。
- 这类题没有唯一标准答案，重点在于「先写、后对、再改」。
- 查看解析时关注句型结构与固定搭配。

#### 阅读理解题（passage）— v3.0.0 新增
- 先阅读英文短文（passage），可参考中文翻译（passageCn）和词汇列表（vocabulary）。
- 短文后附 2-3 道子题（subQuestions），题型为 choice 或 truefalse。
- 子题测试语法结构在语篇中的理解能力，而非单纯内容记忆。
- 每道子题也有独立的解析、知识点、词汇和翻译。

### 3. 查看解析
每道题都附带：
- `explanation`：详细解析（中英混合），告诉你为什么选这个、错在哪里，**重点讲解语法规则**。
- `knowledgePoint`：本题对应的语法知识点，便于回归复习。
- `vocabulary`（v3.0.0 新增）：本题核心词汇列表，含词性与中文释义。
- `sentenceTranslation`（v3.0.0 新增）：英文句子的完整中文翻译。

> 做错的题，请务必点开解析认真阅读，并按 `knowledgePoint` 归类到错题本。

## 四、答题与判分说明

| 题型 | 自动判分 | 判分规则 |
|------|----------|----------|
| 选择题 choice | 是 | 所选字母 == `answer` |
| 判断题 truefalse | 是 | 所选 == `answer`（true/false） |
| 填空题 fillblank | 半自动 | 忽略大小写/首尾空格后与 `answer` 比对；可有可接受变体 |
| 问答题 qa | 否（自评） | 参考答案仅为示例，按要点自评 |
| 阅读理解 passage | 子题自动 | 子题按 choice/truefalse 规则自动判分 |

**填空题判分小贴士：**
- 建议把用户输入与参考答案都做 `trim().toLowerCase()` 后比较。
- 若答案含多个可接受形式（如 `went` 或 `should go`），可配置可接受答案列表。
- 若涉及动词，注意时态与第三人称单数变化。

**问答题自评建议：**
- 句意是否准确表达。
- 语法结构是否正确（时态、主谓一致、词序）。
- 是否使用了题目要求的关键句型/搭配。
- 拼写是否正确。

## 五、推荐刷题流程

1. **热身**：从所选等级的第 1 题开始，按顺序作答（题目由易到难）。
2. **限时训练**：建议每 10 题为一组，选择题 + 判断题控制在 8 分钟内，培养做题速度。
3. **错题复盘**：做错的题先看 `explanation`，再用 `knowledgePoint` 归类到错题本。
4. **二刷**：隔 2~3 天重做错题，检验是否真正掌握。
5. **升级**：某等级正确率稳定在 85% 以上后，进入下一等级。

### 各等级学习重点（语法优先视角）

- **初中（j_）**：打牢 be 动词与主谓一致、一般现在时（第三人称单数）、现在进行时（be+v-ing）、there be 句型（就近原则）与常见介词；掌握疑问句结构与可数/不可数名词判断。
- **高中（s_）**：攻克定语从句（关系代词/副词选择）、名词性从句（that/whether/what）、非谓语动词（to do/doing/done）、时态综合（完成时vs过去时）、虚拟语气与倒装强调。
- **四级（c4_）**：强化从句综合运用（同位语vs定语辨析）、非谓语进阶（独立主格/分词状语）、虚拟进阶（would rather/suggest后虚拟）、倒装综合与长难句结构分析（主干识别/插入语处理）。
- **六级（c6_）**：突破复杂从句嵌套与分隔定语从句、非谓语高级用法（独立结构/不定式被动完成）、虚拟高阶（混合条件句/含蓄虚拟）、学术写作句式（名词化/长定语后置）与语法歧义辨析。

## 六、本地使用与离线访问

题库是单一 JSON 文件，无需联网即可使用。

### 在本地查看题库内容
```bash
# 校验题库是否有效并查看题目总数
python3 -c "import json;d=json.load(open('data/quiz-bank.json',encoding='utf-8'));print('题目总数:',d['meta']['totalQuestions'])"
```

### 按语法分类筛选题目
```bash
# 列出某等级的所有语法类别
python3 -c "
import json
d=json.load(open('data/quiz-bank.json',encoding='utf-8'))
for q in d['levels']['senior']['questions']:
    print(q['id'], q['category'], q['type'])
" | sort
```

### 启动本地静态服务浏览
```bash
# 在项目根目录运行
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/ 即可加载你的刷题页面
# 题库地址：http://localhost:8080/data/quiz-bank.json
```

### 离线导出
- 可将 `data/quiz-bank.json` 按等级或语法分类筛选后导出为 CSV / 打印版，用于无设备环境刷题。
- 也可导出为 Anki 牌组进行间隔重复记忆。

## 七、部署到 GitHub Pages（在线分享）

1. 将整个 `english-quiz-master` 目录推送到 GitHub 仓库。
2. 打开仓库 **Settings（设置）→ Pages**。
3. **Source（来源）** 选择 `Deploy from a branch`。
4. **Branch（分支）** 选择 `main`，文件夹选 `/root`（或你的页面所在目录）。
5. 保存后约 1 分钟，GitHub 会生成访问地址：`https://<你的用户名>.github.io/<仓库名>/`。
6. 任何人通过该网址即可在线刷题，页面通过 `fetch('data/quiz-bank.json')` 读取题库。

> 提示：把刷题页面的 HTML/CSS/JS 放在仓库根目录或 `docs/` 目录，即可被 Pages 直接托管。

## 九、常见问题（FAQ）

**Q1：为什么不再有"词汇"分类？**
A：v2.0 采用语法优先分类法。词汇在语法语境中自然出现——例如考查被动语态的题目会用到各种动词，但测试的是被动结构本身。每道题的解析也聚焦语法规则，而非翻译单词。这样更有利于零基础学习者掌握句法骨架。

**Q2：v3.0.0 新增的 vocabulary 和 sentenceTranslation 有什么用？**
A：`vocabulary` 提供每题 2-5 个核心词汇（含词性与中文释义），帮助学习者在理解语法规则的同时精确定位关键词汇。`sentenceTranslation` 提供英文句子的完整中文翻译，便于中英对照学习。两者都是在语法优先框架下的补充增强，不会改变语法分类主线。

**Q3：passage 题型怎么用？**
A：passage 题包含一段英文短文（3-6 句）及 2-3 道子题。先读短文（可参考 `passageCn` 中文翻译和 `vocabulary` 词汇列表），再做子题。子题测试语法结构在语篇中的理解，子题可按 choice/truefalse 规则自动判分。每个等级 3 道 passage 题，分别对应不同的语法类别。

**Q4：题目答案有争议怎么办？**
A：题库以教学为导向，若发现答案或解析有误，欢迎提 Issue 修正。填空/问答题如有多种合理答案，以参考答案为基准，可自行扩充可接受答案列表。

**Q5：可以做错题本吗？**
A：可以。每题都有唯一 `id` 与 `knowledgePoint`，按 `id` 收集错题、按 `knowledgePoint` 或 `category`（语法类别）归类复习即可。passage 题的子题可通过 `父题id + subType` 定位。

**Q6：题库会更新吗？**
A：题库结构稳定，后续可在各等级 `questions` 数组中追加题目，注意保持 `id` 唯一、题型分布一致（10 choice + 6 truefalse + 6 fillblank + 5 qa + 3 passage），并延续语法优先的 `category` 分类主线。新题也需补充 `vocabulary` 和 `sentenceTranslation` 字段。

**Q7：能在手机上用吗？**
A：可以。题库为纯数据，配合响应式页面即可在手机浏览器刷题；也可部署到 Pages 后随时访问。
